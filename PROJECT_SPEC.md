
# CTO Portfolio Website

## Objective

Build a professional personal website for a UK-based CTO,
software engineer and technology consultant.

The website will showcase professional experience, projects,
technical articles, consultancy services and contact details.

## Technology

- Astro
- TypeScript
- Markdown content collections
- Static site generation
- Responsive CSS
- Cloudflare Pages compatibility
- GitHub source control

## Required pages

### Homepage
Professional introduction, areas of expertise, featured projects,
recent articles and contact call to action.

### About
CTO experience, software engineering background,
cloud infrastructure, AI, automation and security.

### Services
- Fractional CTO consultancy
- Software and API development
- AI integration and automation
- Cloud infrastructure
- Security and DevSecOps
- Technical audits

### Projects
Create a listing page and individual case study pages.

Initial project subjects:
- AI translation management
- Translation memory engine
- AI translation QA
- Automated subtitle platform
- Local LLM development agents
- Cloud-native API development

### Articles
WordPress-style listing page with individual article pages.

Support:
- Categories and tags
- Publication dates
- Featured images
- Related articles
- Reading time
- SEO metadata
- Markdown content

Initial article subjects:
- Running local AI on Apple Silicon
- Building APIs using FastAPI
- AI automation for translation
- Google Cloud Run architecture
- Security considerations for AI agents

### Contact
Contact details, GitHub and LinkedIn links.
Use placeholders where actual details are unknown.

## Design

Professional, modern, responsive website.
Clean typography, strong accessibility and intuitive navigation.

## Requirements

- No database
- No backend server
- All pages statically generated
- Sitemap and RSS
- SEO metadata
- No fabricated professional achievements
- Cloudflare-compatible production build

## Quality assurance

Implement and execute:
- Build checks
- TypeScript/Astro checks
- Browser navigation tests
- Article and project route tests
- Responsive navigation tests

## Development process

1. Plan the implementation
2. Scaffold the project
3. Build shared components
4. Build core pages
5. Build article system
6. Build project system
7. Generate draft content
8. Implement SEO
9. Run automated tests
10. Fix failures
11. Document results

Maintain PROGRESS.md.

Create meaningful local Git commits after successful milestones.

Do not push to GitHub or deploy without permission.

## Definition of done

The website must build successfully, contain all required
pages and pass its automated acceptance tests.
